# Instagram profile — @monkmanthra

The Graph API has **no endpoint for bio, profile picture, category or
website**. Every tool Meta exposes is for publishing and reading media,
comments and insights. `INSTAGRAM_UPDATE_MESSENGER_PROFILE` is the DM-bot
greeting, not the profile. So everything on this page is set by hand in the
app; it lives here so it does not drift from the site copy.

## Profile picture

`assets/img/instagram-pfp.png` — 1080x1080, generated by `make-pfp.py`.

This is the **reduction**: one gold ring and the seed, not the full three.
That is Section Two's own rule, not a compromise made for Instagram. Tested
before choosing: at 44px the full mark's 2.4-unit strokes render 0.74px wide
and the three rings merge into a smudge. The reduction's stroke lands at
1.9px and stays a mark. `instagram-pfp-full.png` keeps the three-ring version
for anywhere it is shown large.

Instagram crops to a circle. The ground is painted full-bleed square so the
crop can only ever remove purple.

## Website

Instagram will not accept plain text here — the field validates as a URL, so
"coming soon" cannot go in it. Three honest options:

1. **Leave it empty.** The bio already says coming soon. Cleanest.
2. **Point it at the live site**, if it is ready to be seen.
3. **Add a link with a custom title.** Instagram allows up to 5 links, each
   with a display title of your choosing — the title can read "Coming soon"
   but a valid URL still has to sit behind it.
